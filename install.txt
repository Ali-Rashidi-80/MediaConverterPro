Galaxy Media Pro 3.0 — Quick install pointer
=================================================

Default language of documentation: English
Persian README: README.fa.md

Full documentation:

  README.md           — overview & quick start (English default)
  README.fa.md        — overview (Persian)
  docs/INSTALL.md     — complete install & build guide
  docs/INDEX.md       — all documentation
  CONTRIBUTING.md     — contribution policy
  SECURITY.md         — vulnerability reporting

Quick run:
  pip install -r requirements.txt
  python galaxy_ultimate.py

Portable build:
  build.bat / build_portable.bat  →  dist\GalaxyMediaPro_Portable.exe
  build_onedir.bat                →  onedir folder under dist\

QA:
  pip install -r requirements-dev.txt
  python tools/qa_full.py --full
